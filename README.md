# HandyExtension

A Microsoft PowerToys Command Palette extension for Handy.

HandyExtension is an independent, open-source project that provides quick access to Handy's transcription controls from the PowerToys Command Palette.

Disclaimer: HandyExtension is not an official Handy project and is not affiliated with or endorsed by the Handy maintainers. Handy is a separate project; its name and branding belong to their respective owner.
